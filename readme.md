# **How to clone it**

Remove anything that's there inside the include folder and then clone the repo directly inside `/usr/local/include`:

```bash
cd /usr/local/include
git clone https://github.com/prsweet/pbds-for-clang.git .
```

If you have something that's important to you, clone it somewhere else and copy the file structure as is, because the same structure is in GCC and hence required by online judges like Codeforces, Atcoder...
